# App icons

The dock loads real macOS icons from this folder when present, and falls back
to built-in SVG recreations otherwise. To get authentic macOS icons:

1. Download a macOS icon pack — a good free source is **https://macosicons.com**
   (or export from your own Mac).
2. Save each as a **PNG** in this folder with these exact names:

   - `finder.png`
   - `notes.png`
   - `safari.png`
   - `photos.png`
   - `messages.png`
   - `mail.png`
   - `terminal.png`

   (Optionally `resume.png`.)

3. Refresh — the dock picks them up automatically. Square PNGs around
   256×256 or 512×512 look best.
